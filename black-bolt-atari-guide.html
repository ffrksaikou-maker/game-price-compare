2025年6月6日発売の SV拡張パック「ブラックボルト」(sv11B) は、イッシュ地方(BW)のポケモンを主役に据えた特別弾で、姉妹弾「ホワイトフレア」(レシラムex)と対を成す構成です。本記事では、当たりカードのランキング・収録レアリティ・買取相場・封入率・見分け方を、複数ソースと当サイトの実データをもとに整理します。BOXの店舗別最新買取は ブラックボルト個別ページ で毎日更新しています。

ブラックボルト(sv11B)とは｜基本情報

  • 発売日: 2025年6月6日(金)
  • 定価: 1BOX ¥5,800(税込) / 1パック ¥290(税込・7枚入り) / 20パック入り
  • 型番: sv11B(SVシリーズ拡張パック)
  • シリーズ: スカーレット&バイオレット(SV)
  • 看板(最高当たり): ゼクロムex BWR / SAR
  • 収録レアリティ構成: BWR(新レアリティ) / SAR(7種) / AR(72種) / SR(8種) / UR / ACE SPEC
  • テーマ: 姉妹弾ホワイトフレアと合わせてイッシュ地方のポケモン156種がAR/SARで登場 — BW世代のファン需要が話題
  • 現在のBOX買取相場: 約¥26,000(定価の約4.5倍・2026年7月時点、当サイト7店舗最高値)

本弾最大の目玉は、ブラックボルトで初導入された新レアリティ BWR(ビーダブリューレア)。BWRに該当するのは ゼクロムex 1種のみで、カード全体を黒で覆うBW世代オマージュの特別仕様が話題を呼びました。この超低封入・高相場のBWRがBOX価格(定価の約4.5倍)を支えています。BOX相場は直近で過去30日の最高値を更新する上昇基調にあり、同時期のSV拡張パックである ロケット団の栄光 や 超電ブレイカー と並ぶ人気弾です。

看板当たり「ゼクロムex BWR」

本商品の価値の中心が、看板の ゼクロムex BWR(ビーダブリューレア) です。2026年7月時点の買取相場は 約¥50,000、フリマ販売相場は約¥75,000前後で取引されます。BWRはブラックボルトで初導入された新レアリティで、該当カードは ゼクロムex 1種のみ。封入率は 約20〜24BOXに1枚(約4〜5%) と極めて低く、カード全体を漆黒で染めるBW世代オマージュの特別デザインがコレクター人気を集めています。発売直後の5万円台から半年でじりじりと相場を切り上げ、2026年に入っても上昇基調が続いています。姉妹弾ホワイトフレアの レシラムex BWR と対になるコレクション性も需要を支えています。相場推移の全体像は ブラックボルト個別ページの価格チャート もあわせてご覧ください。

次点の当たり｜SAR/AR枠

ゼクロムex SAR(約2.5万円・約6BOXに1枚)

第2の当たりが ゼクロムex SAR。買取は 約¥25,000です。イラストは人気イラストレーター danciao氏が担当し、伝説ポケモン・ゼクロムを大胆に描いた全面仕様が高評価。封入率は 約6BOXに1枚で、一定の流通量がありつつもイラスト人気で需要が底堅く、横ばい〜堅調で推移しています。

ガマゲロゲ AR(約8,000円・kandata氏イラスト)

AR枠ながら本弾屈指の人気を誇るのが ガマゲロゲ AR(約¥8,000)。ギラティナやコイキング等の高額イラストを手掛けた kandata氏のイラストで、絵の中に「666」が隠れているとして話題化し、発売当初の2,000円前後から大きく高騰しました。AR全72種のなかでも別格の存在です。

Nの筋書き SAR / キュレムex SAR ほか

BWの人気ライバル・NのサポートSAR Nの筋書き SAR は買取 約¥4,500。ただし発売初動の販売相場約2.4万円からは調整が進み、現状は落ち着いた水準です。続いてキュレムex SAR(約¥4,000)、ジャローダex SAR(約¥3,000)、メロエッタex SAR・ゲノセクトex SAR(各約¥2,500)がBOX相場を底支えするSAR枠です。

封入率まとめ

  • ゼクロムex BWR: おおよそ約20〜24BOXに1枚(約4〜5%)。BWRはゼクロムex1種のみの新レアリティで、カートンを複数開けてようやく1枚という水準
  • SAR(全7種合計): 情報源により約5〜6BOXに1枚と幅があります
  • 狙いの1種(例:ゼクロムex SAR): SARが7種のため、自引き確率はさらに下がります
  • AR(全72種): 各BOXに3〜4枚封入されますが、種類が多く狙い引きは困難
  • UR・ACE SPEC: 各BOXに一定数封入

※封入率はカードショップ等の大量開封報告に基づく推定値で、公式発表ではありません。「SARが当たる確率」と「狙いのゼクロムex SARが当たる確率」は別物である点に注意してください。とくにBWRの約20〜24BOXに1枚は、1BOX単位での自引きが極めて難しい水準です。

当たりの見分け方｜開封のポイント

結論: 拡張パックは外から中身を見分ける方法は基本的にありません。パックの重さでの判別は不確実で、店頭での測定はマナー違反です。

ブラックボルトは20パック入り(1パック7枚)のBOX形式です。開封後は、BWR・SARのイラスト全面仕様や箔押しでレアリティを判別しましょう。看板の ゼクロムex BWR はカード全体を黒で覆う唯一無二の特別加工が目印で、一目で他レアリティと区別できます。SARは総枚数を超える番号(例:169/086 など「/086」の分母超え)が振られ、イラスト全面の美麗仕様が特徴。ARはキラ加工のイラストレア枠で、ガマゲロゲ ARのような人気絵師の1枚に該当するかを確認しましょう。

開封すべき？BOX開封の期待値と注意点

看板の ゼクロムex BWRは約20〜24BOXに1枚で、1BOX(定価¥5,800)開封での自引きは容易ではありません。第2の当たりであるゼクロムex SAR(約2.5万円)を引ければBOX代を大きく上回りますが、SARも7種のうちの1枚。一方で、未開封BOXの買取相場は 約¥26,000(定価の約4.5倍) で、確実に価値を取りたいなら 最高値の買取店で未開封のまま売る のが堅実です。ゼクロムexのキャラ人気とBWデザインに賭けて自引きを楽しむなら開封、というハイリスク・ハイリターンの整理になります。BOX相場は現在上昇基調にあるため、売却タイミングを計るなら 週間価格変化ランキング もあわせてチェックしましょう。相場サイクルの考え方は BOX投資の始め方、当たりを引いた後の売り方は 開封→シングル売りで利益を出す方法 が参考になります。
