【2026年9月最新】エリカの招待SARの買取価格と相場推移｜初動12.8万円から¥5,000へ

公開: 2026年4月14日 / 更新: 2026年9月1日 / ポケモンカード151(SV2a)収録 / ポケカ買取チェッカー編集部
2026年9月1日時点 買取価格
¥5,000 (PSA10: ¥27,500)
初動¥128,200 → 現在¥5,000台。4月の月間最高¥9,485から約-47%。親BOX151(同期間-25%)より下げが大きく、連動は対称ではありません

ポケモンカード151の象徴的な1枚、「エリカの招待 SAR」。草花を愛でる絵画のようなイラストで、コレクターからの人気は絶大です。2026年9月1日時点の買取相場は約¥5,000、PSA10鑑定済みは約¥27,500。初動の¥128,200からは大きく下げており、2026年4月に付けた月間最高¥9,485からも約-47%の水準です。親BOXであるポケモンカード151と連動して動きますが、上げには鈍く下げにはきついという非対称があります。本記事では、価格推移・151 BOXとの連動の実態・人気の理由・今後の見方を、当サイトの実データで整理します。

エリカの招待SARとは｜基本情報

  • 収録パック: 強化拡張パック「ポケモンカード151」(SV2a)
  • カード番号: 206/165
  • レアリティ: SAR (スペシャルアートレア)
  • カード種別: サポート (トレーナーズ)
  • イラストレーター: 二反田こな氏 (ポケモンカード初担当)
  • 封入率: 151の SAR全体が約5〜6BOXに1枚、エリカの招待SAR単独では1BOXあたり約0.03%

エリカは初代ポケモン赤・緑に登場したタマムシシティのジムリーダーで、草タイプを得意とする人気キャラクター。SARのイラストでは、色とりどりの草花に囲まれ慈愛に満ちた眼差しを向けるエリカが描かれており、ポケカ史上最高峰の美麗カードの1つとして評価されています。

価格推移｜初動¥128,200から現在¥5,000へ

2023年6月 発売直後 → 初動販売相場は約¥128,200。SAR全体の注目度が極端に高く、プレ値で取引
2023年後半 → 151の受注生産や再販に合わせて相場は下落、¥20,000〜¥50,000台で推移
2024年〜2025年 → 151の継続的な再販により¥10,000前後まで調整、一時¥7,000台まで下落
2026年3月 → ¥7,500前後で推移
2026年4月 ¥8,000 → 151 BOX本体の急騰に連動して再び上昇。月間最高¥9,485を記録
2026年9月 ¥5,000 → その後は反落し、9月1日時点で¥5,000前後。PSA10も約¥37,400から約¥27,500へ調整

「初動高騰 → 再販による調整 → 絶版観測で一時反発 → 再下落」という推移です。2026年4月の反発は続かず、9月にかけて反発が始まる前の水準(3月の¥7,500)も割り込みました。現在の¥5,000台は、当サイトが追跡している範囲では最も安い水準です。「151が絶版に近づけばエリカSARも上がる」という説明をよく見かけますが、次章のとおり実データでは上げ幅と下げ幅が釣り合っていません。

【検証】151 BOXとの連動は対称ではない

エリカの招待SARは「親BOXの151が上がれば連動して上がる」と語られがちなカードです。当サイトは151 BOXの買取価格を最大9店舗から毎日自動取得しているので、実際に連動しているのかを数字で確かめられます。

時期151 BOX買取(当サイト実データ)エリカの招待SAR
2026年3月上旬¥41,724約¥7,500
2026年4月21日(BOXのピーク)¥71,000約¥9,485(月間最高)
2026年9月1日¥53,000約¥5,000

ここから読み取れるのは、連動はしているが幅がまったく釣り合っていないということです。

  • 上げ局面: 151 BOXが¥41,724 → ¥71,000と+70%上がったあいだ、エリカSARは¥7,500 → ¥9,485の+26%にとどまりました
  • 下げ局面: BOXがピークから¥53,000へ-25%下げたのに対し、エリカSARは-47%と倍近く下げています
結論: エリカの招待SARは151 BOXに対して上げには鈍く、下げにはきつい動き方をします。「BOXが上がるからカードも上がる」という前提で買うと、上昇局面では思ったほど取れず、下落局面では余計に削られます。

BOX価格に対するカードの比率で見ても、4月のピーク時は0.134倍(¥9,485 ÷ ¥71,000)だったものが、9月には0.094倍(¥5,000 ÷ ¥53,000)まで下がっています。BOXの中でのエリカSARの相対的な位置づけ自体が下がっている、という見方もできます。

151 BOX本体の相場と絶版観測については ポケモンカード151の高騰解説 で扱っています。最新のBOX買取価格は 151 BOXの買取価格ページ で毎日更新しています。

それでも人気が根強い5つの理由

理由1: ポケカ史上屈指の絵画的イラスト

SARイラストは、花畑で植物を愛でるエリカを柔らかい色彩で描いたまるで絵画のようなビジュアル。ポケモンカードのトレーナーズSARの中でも特に完成度の高いイラストとして知られています。キャラクターの表情・背景の植生・光の表現すべてが緻密で、コレクション需要は圧倒的です。

理由2: 初代赤・緑からの歴史とキャラクター人気

エリカは1996年発売の初代ポケモン赤・緑に登場したタマムシシティのジムリーダー。30〜40代のポケモン世代にとっては思い出補正が強く、「初代151匹」をテーマにしたポケモンカード151というパックのコンセプトと完全に一致する存在です。昔からのポケモンファンのノスタルジー需要が根強い下支えになっています。

理由3: イラストレーター二反田こな氏の評価

本作のイラストはフリーランスのアニメーター・イラストレーター二反田こな氏が担当しており、これが同氏にとって初めてのポケモンカード参加作品です。その後も二反田氏が手掛けたカードはいずれも高い評価を受けており、「二反田コレクター」とも呼ばれるファン層が存在します。エリカSARはその原点として特に人気です。

理由4: 封入率 5〜6BOXに1枚の希少性

151のSAR全体の封入率は約5〜6BOXに1枚(約17〜20%)で、151に収録されるSARは計8種類。エリカの招待SARを狙い撃ちで自引きする確率は1BOXあたり約0.03%に過ぎません。100BOX開封しても3回程度しか出ない計算で、この絶対的な希少性が高値を支えています。

理由5: 親BOX「ポケモンカード151」の絶版観測

エリカの招待SARの価格は、親BOXであるポケモンカード151の流通量に直結します。151は2024年11月以降大規模再販が確認されておらず、2026年1月23日にGレギュレーションがスタン落ち済み(大会使用不可)のため、事実上の絶版状態との見方が広がっています。151 BOXが急騰する局面では、エリカSARも連動して再評価される構図です。詳細は 【特集】ポケモンカード151高騰解説 を参照してください。

カード効果・対戦性能

カード種別はサポート(トレーナーズ)で、効果は以下の通りです。

「相手の手札を見て、その中からたねポケモンを1枚選び、相手のベンチに出す。その後、そのポケモンをバトルポケモンと入れ替える。」

対戦での評価は限定的です。「相手の手札にたねポケモンがいること」が発動条件のため、タイミングが限られます。サイドを2枚取れる低HPのたねポケモンを引きずり出して実質《ボスの指令》として使う、または「にげる」コストが重いポケモンを出して動きを止める、といったトリッキーな運用が可能ですが、汎用性の高いカードとは言えません。

つまりエリカの招待SARの価格は、ほぼ100%コレクション需要で支えられています。これはコレクター向けカードの典型パターンで、相場は「プレイ需要の実需」ではなく「供給の希少性」と「イラストの評価」で決まります。

PSA10鑑定の価値｜ノーマルの約5.5倍

状態の良いエリカの招待SARをお持ちの場合、PSA鑑定も有力な選択肢です。

  • PSA10相場: 約¥27,500 (2026年9月1日時点)
  • ノーマル相場: 約¥5,000
  • 価格倍率: PSA10はノーマルの約5.5倍
  • PSA10取得率: 59.3% (PSA10総枚数 13,350枚)

取得率が59.3%とやや高めなので、状態が良ければ比較的鑑定成功の可能性があります。ただしPSA鑑定には送料・手数料・時間(数ヶ月〜)がかかるため、費用対効果を考えてから申請しましょう。詳細な鑑定の流れは PSA鑑定ガイド で解説しています。

今後の3シナリオ

現在の¥5,000を起点に整理します。前提として、エリカSARは151 BOXの動きを増幅して受けるため、BOX側がどう動くかが出発点になります。

強気シナリオ
¥8,000〜¥10,000

151 BOXが4月のピーク(¥71,000)水準を回復する展開。BOXが+30%程度戻れば、4月の月間最高¥9,485の再現が視野に入ります。ただし上げ局面ではカードの反応が鈍い(BOX+70%に対しカード+26%)ため、BOXの上昇率をそのまま当てはめると過大評価になります。

中立シナリオ
¥4,000〜¥6,000

最も現実的なレンジ。151 BOXが¥50,000台で横ばいを続ける場合、エリカSARも現状水準で推移します。イラスト人気による下支えはあるものの、能動的に買われる材料は現時点で見当たりません。

弱気シナリオ
¥3,000前後

151 BOXの下落が続く、または新弾で注目のトレーナーSARが登場して関心が移る展開。下げ局面ではカードのほうが大きく削られる(BOX-25%に対しカード-47%)ため、BOXが¥45,000程度まで下げると¥3,000台が視野に入ります。

過去の予想の答え合わせ: 本記事は2026年4月時点で強気¥15,000〜¥25,000・中立¥9,000〜¥13,000・弱気¥5,000〜¥7,000という3シナリオを掲載していました。実際は弱気シナリオの下限に到達しています。当時は151 BOXの上昇が続く前提で組んでいましたが、BOXは4月をピークに反落しました。予想を外した事実として残しておきます。
