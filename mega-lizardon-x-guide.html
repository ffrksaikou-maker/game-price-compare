【2026年8月最新】メガリザードンXex MUR/SARはなぜ高い？¥130,000超え｜相場推移と今後の予想

公開: 2026年4月14日 / インフェルノX(M2)収録 / ポケカ買取チェッカー編集部
2026年8月26日時点 買取相場
MUR ¥130,000 / SAR ¥95,000
PSA10: MUR ¥620,000 / SAR ¥186,000 — MURは1ヶ月で約1.8倍に急騰

2025年9月26日発売のMEGA拡張パック「インフェルノX」を象徴するメガリザードンXex MUR / SAR。2026年8月26日時点でMUR買取は¥130,000、SARは¥95,000、PSA10ではMURがなんと¥620,000に達しています。発売からわずか半年、1ヶ月でMURが約1.8倍に急騰した異例の上昇を、封入率・イラストレーター・5つの高騰理由・今後の予想と併せて徹底解説します。

メガリザードンXex MUR / SARとは｜基本情報

  • 収録パック: MEGA拡張パック「インフェルノX」(M2)
  • カード番号: MUR 116/080 / SAR 110/080
  • レアリティ: MUR(マスターウルトラレア)、SAR(スペシャルアートレア)
  • イラストレーター(MUR): たくよあ(takuyoa)氏
  • 封入率(MUR): 約2%(約50BOXに1枚)
  • 封入率(SAR): 約6BOXに1枚

MUR(マスターウルトラレア)は、前弾「メガブレイブ」「メガシンフォニア」から新たに導入された最上位レアリティ。金色をベースにしたホログラム加工に角度で変化する虹色光沢を加えた極めて豪華な仕上がりで、開封すれば誰もが目を奪われる特別感があります。

2026年4月8日 MUR ¥130,000 / SAR ¥95,000 → 現在水準。1ヶ月でMUR約1.8倍・SAR約1.4倍の急騰

注目すべきはPSA10相場の伸びです。MUR PSA10は1ヶ月で¥345,000→¥620,000(+80%)、SAR PSA10は¥140,000→¥186,000(+33%)と、鑑定済みの伸びがノーマル以上に急激です。これは「MURレアリティ」そのものへの市場注目度が高まっている証拠で、鑑定価値のある個体は取引が活発化しています。

なぜこんなに高い？【5つの理由】

理由1: 約50BOXに1枚のMUR希少性

MURの封入率は約2%で、1BOXに入っている確率はほぼない水準です。「3カートン(約90BOX)開封してようやく1枚」という希少さで、たとえBOX単価が¥5,400でも3カートンで約¥486,000の開封コストが必要。自引きするより買った方が合理的な価格帯に達しており、市場での流通量が極めて少ないことが相場を押し上げています。

理由2: リザードン人気の集大成「メガ進化形態」

ポケモン歴代トップクラスの人気キャラクター「リザードン」。そのメガ進化形態(X/Y)は特にファンが多く、2025年のMEGA拡張パックはリザードン人気の集大成として市場の注目を集めました。 黒炎の支配者のリザードンex SAR、ポケモンカード151のリザードンex SARと並び、リザードン系カードは例外なく高額化する傾向が継続しています。

理由3: たくよあ氏の名作イラスト

MURのイラストは たくよあ(takuyoa)氏 が担当。メガ進化の迫力と黒い炎を纏った姿が印象的で、金色ホログラム加工との相性も抜群。コレクター間で「歴代MUR最高の仕上がり」との評価も多く、イラスト品質が価格を下支えしています。

理由4: 対戦環境での実用性

メガリザードンXexはワザ性能・HPともに高く、対戦環境でも採用候補になる強力なポケモンです。MUR/SAR はそのままプレイできる仕様のため、コレクター需要だけでなくプレイヤー需要も併せ持つのが大きな特徴。実需と投機需要の両軸が価格を支えています。

理由5: MEGA拡張パック第2弾の節目

インフェルノXはMEGAシリーズ第2弾。前弾メガブレイブ・メガシンフォニアと異なり、リザードン単独主役のMEGA弾という位置づけが特別感を生んでいます。前弾MURの相場推移を参考に投資家が早めに仕込む動きがあり、供給不足と需要集中で急騰につながりました。

PSA10鑑定の価値

  • MUR PSA10相場: 約¥620,000 (ノーマル¥130,000の約3.1倍)
  • SAR PSA10相場: 約¥186,000 (ノーマル¥95,000の約2倍)
  • PSA10取得率・総枚数は2026年4月現在公開データが限定的

MURのPSA10は発売から半年での評価としては異例の高値で、ノーマルの3倍以上の価格差がついています。状態の良い個体ならPSA鑑定経由の利益率が極めて高く、投資価値のあるカードと言えます。ただしMURは元々希少で、鑑定に出す前に紛失・損傷のリスクも大きいため、慎重な取扱いが必要です。詳細な鑑定フローは PSA鑑定ガイド を参照してください。

今後どこまで上がる？【3シナリオ】

強気シナリオ
MUR ¥300,000〜¥500,000 / SAR ¥130,000〜¥130,000

インフェルノX BOX本体が定価の10倍超(¥55,000〜¥70,000)に達し、MUR/SARがBOX相場の約4〜5倍で定着する展開。MEGAシリーズが再販停止に向かい、リザードンの歴史的人気と相まってコレクター需要が集中。過去の高額MURカード(メガリザードンYex等)の軌道を考えれば十分視野に入る水準です。

中立シナリオ
MUR ¥180,000〜¥250,000 / SAR ¥85,000〜¥120,000

現在の急騰直後は短期的に調整が入り、¥180,000前後で下値を固めた後、緩やかに上昇継続するシナリオ。再販ペースが徐々に落ちる中で、BOX本体の相場と連動して長期上昇。2026年後半に新たな高値を更新する可能性が高いレンジです。

弱気シナリオ
MUR ¥120,000〜¥160,000 / SAR ¥60,000〜¥80,000

MEGA拡張パックの大規模再販が実施された場合、または新弾で別のリザードン系MURが登場した場合のシナリオ。供給急増で一時的に相場が調整するが、リザードン人気は不変のため底値は堅い。1ヶ月で+80%の急騰後には、このレベルの調整も想定の範囲内です。

今買うべき？今売るべき？

  • 新規購入: 1ヶ月で+80%の急騰直後のため、短期的な調整リスクあり。MUR¥180,000前後までの押し目を待つのが無難。長期保有前提なら現在水準での仕込みも選択肢。
  • 既に保有(MUR): 発売時¥100,000前後で購入した分は利益2倍以上。急騰後のピークを読むのは困難なので、「半分売却+半分保有」の分散戦略がリスクバランス最適。
  • 既に保有(SAR): SARもMUR連動で上昇しているが、価格がMURほど急騰していない分、さらなる追随余地あり。保有継続の選択肢が濃厚。
  • PSA鑑定検討中: PSA10相場は極めて高額(MUR¥620,000、SAR¥186,000)。状態が極上なら鑑定価値は絶大。ただし移送事故・鑑定失敗のリスクも大きいため、保険付き配送など慎重な取扱いを。
