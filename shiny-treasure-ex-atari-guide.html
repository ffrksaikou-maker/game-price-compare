2023年12月1日発売の SVハイクラスパック「シャイニートレジャーex」 は、色違い(シャイニー)ポケモンを大量収録した年末のハイクラスパックです。発売から2年半以上が経った2026年7月時点でもBOX買取が定価の約3.6倍を維持しており、SVシリーズの中でも息の長い高額弾となっています。本記事では当たりカードのランキング・買取相場・封入率・見分け方を、複数の公開情報と当サイトの実データで整理します。

シャイニートレジャーexとは｜基本情報

  • 発売日: 2023年12月1日(金)
  • 定価: 1BOX ¥5,500(税込) / 1パック ¥550(税込) / 10パック入り
  • 種別: ハイクラスパック(高レアリティ比率が高い年末商品)
  • レギュレーションマーク: G(2026年1月23日のレギュレーション変更でスタンダードから外れました)
  • 看板(最高当たり): ミュウex SAR
  • 収録レアリティ構成: SAR(8種) / UR(6種) / SSR / SR / AR / S(色違い) ほか
  • 現在のBOX買取相場: ¥20,000(定価の約3.6倍・2026年7月時点、当サイト掲載9店舗の最高値)

ハイクラスパックは1BOX10パック入りと、通常の拡張パック(30パック入り)に比べてパック数が少ない代わりに高レアリティの比率が高い商品設計です。定価¥5,500に対して1パック¥550と単価も高く、「BOXあたりの当たり枚数」ではなく「パックあたりの濃さ」で評価するのが正しい見方になります。

看板当たり「ミュウex SAR」

本商品の価値の中心が、看板の ミュウex SAR です。2026年7月時点の買取相場は 約¥74,000、PSA10では約¥135,000前後で取引されます。幻のポケモンであるミュウの知名度、日本国内にとどまらない海外コレクター需要、そしてSARが8種しかない構成による希少性——この3点が重なり、SVシリーズのハイクラスパックでも屈指の高額カードとなっています。

相場は直近1か月で約¥72,000から約¥74,000へと小幅に上昇しており、発売から2年半を経てなお底堅い需要を示しています。単体で7万円を超えるカードはポケモンカード151など限られた弾にしか存在せず、BOX買取¥20,000の大部分がこの1枚への期待値で説明できる構図です。

次点の当たり｜SAR枠と色違い(S)枠

リザードンex SAR(約3万円)

2番手が リザードンex SAR(約¥30,000)。リザードンはポケモンカード全体を通じて相場を牽引し続けるキャラで、黒炎の支配者やリザードン収録BOXでも同様に最上位を占めています。同じリザードンexでもSSR版は約¥2,800と、SARとは10倍以上の開きがあります。

サーナイトex SAR / ナンジャモ SAR / ボタン SAR

サーナイトex SAR(約¥12,000)、ナンジャモ SAR(約¥7,000)、ボタン SAR(約¥2,000)が続きます。ナンジャモはSVシリーズを代表する人気キャラで、シャイニートレジャーexのSAR版もコレクター需要が根強い1枚です。

色違い(S)枠｜ピカチュウ・ミミッキュ・カビゴン

本商品最大の個性が色違いポケモンを大量収録した「S」枠です。ピカチュウ S(約¥6,000)はSARのボタンを上回る水準で、ミミッキュ S(約¥2,000)、カビゴン S(約¥1,900)も安定しています。SARを外しても色違い枠で一定の回収が見込めるのが、開封勢からの評価が高い理由です。

封入率まとめ

  • SAR(8種合計): 封入率は約12%(およそ8.3BOXに1枚)。狙いの1種(例:ミュウex SAR)を自引きする確率は約1.5%と報告されています
  • UR(6種): 封入率は約8%(およそ12.5BOXに1枚)
  • SSR・SR・AR・S(色違い): 各BOXに一定数封入され、色違い枠にも数千円クラスが複数あります
ポイント: 1BOXは10パック入りと少ないため、「SARが約8.3BOXに1枚」は約83パックに1枚という計算になります。30パック入りの拡張パックと同じ感覚でBOX数を比べると誤読するので注意してください。

※封入率はカードショップ等の大量開封報告に基づく推定値で、公式発表ではありません。「SARが当たる確率(約12%)」と「狙いのミュウex SARが当たる確率(約1.5%)」は別物である点に注意しましょう。SARが33種あるテラスタルフェスexと比べると、本商品はSARが8種と少ないぶん1枚引けたときの当たり率は高いという関係になります。

当たりの見分け方｜開封のポイント

結論: ハイクラスパックも外から中身を見分ける方法は基本的にありません。パックの重さでの判別は不確実で、店頭での測定はマナー違反です。

開封後はカード全面がイラストになっているかでSARを判別します。SARはカード番号が収録総数を超える「超え番号」が振られており、これが最も確実な目印です。混同しやすいのがSSRで、こちらは色違いポケモンのex版に付く特別仕様ですが、イラストは全面ではなく通常の枠内に収まっています。前述のとおりミュウex・リザードンexはSARとSSRで10倍以上の価格差があるため、ここを取り違えると売却額が大きく変わります。

色違い(S)枠は通常版と同じイラスト構図でポケモンの体色だけが異なる仕様です。見落としやすいので、開封時はポケモンの色を意識して確認してください。

レギュレーション｜スタン落ち後も相場が落ちない理由

シャイニートレジャーexはレギュレーションマークGに該当し、2026年1月23日のレギュレーション変更でスタンダードから外れました。現在スタンダードで使えるのはH・I・Jのカードのみです。

それでもBOX買取は定価の約3.6倍(¥20,000)を維持しています。これは本商品の相場を支えているのが対戦需要ではなくコレクション需要だからです。ミュウex SAR・リザードンex SAR・色違い枠はいずれも「飾る・集める・鑑定に出す」目的で買われており、スタンダードで使えるかどうかは価格形成にほとんど影響していません。同じ構造はイーブイヒーローズのような旧シリーズの高額弾にも共通します。

開封すべき？BOX開封の期待値と注意点

看板の ミュウex SARは狙いの1枚として約1.5%という水準で、1BOX(定価¥5,500)開封での自引きは現実的ではありません。期待値の観点では、未開封買取(¥20,000・定価の約3.6倍)を取るのが堅実な選択です。一部メディアの試算ではBOX開封時の期待値を約8,300円としており、これは未開封買取¥20,000を大きく下回ります。

ただし本商品は色違い(S)枠に数千円クラスが複数あるため、SARを外しても中位カードの積み上げで一定の回収が見込める構成でもあります。確実に価値を取りたいなら未開封のまま 最高値の買取店で売る、ミュウex SARに賭けて自引きを楽しむなら開封、という整理です。開封して1枚ずつ売る場合の手順は 開封→シングル売りで利益を出す方法、鑑定を含めた出口戦略は PSA鑑定ガイド をご覧ください。
